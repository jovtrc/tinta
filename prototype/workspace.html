Local setup

MSEdited by Maria Souza · 2 hours ago

Everything you need to run the Acme app on your machine. The first time takes about 20 minutes.

💡

You need Docker Desktop and Node 24 before you start. If a step here is out of date, add a note so the next person doesn't get stuck.

1. Get the code

Clone the repository and install the dependencies. The first install downloads about 2 GB, so use a good connection. 11 2 

git clone git@github.com:acme/app.git
cd app && pnpm install
1

2. Start the stack

  1. Copy .env.example to .env.
  2. Run pnpm dev. The app opens at localhost:3000.
  3. Sign in with your work account.

What you're looking at

#WordPress core#Liber
  1. 1Workspace mode. A normal wp-admin page with the WordPress menu and toolbar hidden. With option C the address is post.php?post=42&action=edit.
  2. 2Workspace name and icon are the site's Title and Site Icon.
  3. 3Search opens WordPress's command palette. Liber adds page search and its own commands.
  4. 4Pinned and Recent, saved per person.
  5. 5Page tree. Drag to reorder or move a page. Hover shows ⋯ and + for a subpage.
  6. 6Trash is WordPress's trash. Subpages go with their parent; trash empties after 30 days.
  7. 7Account menu: profile and color scheme, Admin tools (admins), log out.
  8. 8Breadcrumb and save status. With option C, core's editor header is restyled to look like this.
  9. 9Notes and History: WordPress Notes (on blocks and selected text, with @mentions) and visual revisions.
  10. 10Page icon: Liber's small emoji picker.
  11. 11The block editor: title, blocks, block toolbar and the / menu, limited to the allowed blocks.
  12. 12Callout and Page link are Liber's only two blocks.
  13. 13Colors come from each person's admin color scheme (Users → Profile).
